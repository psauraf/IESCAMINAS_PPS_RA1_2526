# Apartado 3 – Resultados del tutorial LearnGitBranching

## 📌 Descripción del apartado

En este apartado se documentan los resultados obtenidos tras completar el tutorial interactivo de **LearnGitBranching** disponible en:

> https://learngitbranching.js.org/

Este tutorial forma parte de la práctica previa **ACT_RA1_4: Solidity + GIT** y está orientado a afianzar los conocimientos sobre control de versiones con Git, especialmente en lo relativo a:

- Ramas locales (`branch`)
- Fusiones (`merge`)
- Reescritura de historia (`rebase`)
- Trabajo con repositorios remotos (`remote`, `push`, `pull`, `fetch`)

El objetivo de este apartado es dejar constancia gráfica de que el alumno ha realizado el tutorial completo tanto en la parte **Main (Principal)** como en la parte **Remote (Remota)**.

## 🎯 Relación con el RA1 de Puesta en Producción Segura

El contenido de este apartado está directamente relacionado con el **Resultado de Aprendizaje 1 (RA1)**, ya que:

- Dominar Git y el trabajo con ramas es imprescindible para gestionar código en entornos colaborativos y de producción.
- El uso de ramas y repositorios remotos favorece:
  - la trazabilidad de cambios,
  - el control de versiones,
  - la integración controlada mediante *pull requests*,
  - y la minimización de riesgos al desplegar nuevas versiones.

El tutorial de LearnGitBranching proporciona una base sólida y visual para comprender estos conceptos y aplicarlos posteriormente en proyectos reales, como el resto de apartados de esta práctica.
